# Fundo de reunião (Zoom / Meet / Teams)

- `tratto-zoom-bg-dark.png` — 1920×1080, pronto pra usar.
- `background.html` — fonte editável. Cores nas variáveis `:root`.
- `assets/tratto-logo-original.jpg` — logo enviada; `assets/tratto-logo-cream.png` é o recorte com fundo transparente usado no HTML.
- `render.mjs` — gera o PNG: `node render.mjs` (precisa de Playwright + Chromium).

Se a logo vetorial (SVG/PDF) aparecer, troque o `<img>` no HTML por ela pra ficar mais nítida.
